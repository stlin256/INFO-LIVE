### [“大牙刷”崛起：我们的口腔是如何变成一个利润丰厚的市场的？](https://www.theguardian.com/society/2026/sep/22/the-rise-of-big-toothbrush)
<div class="original-title-sub"><span class="orig-tag">原文</span> The rise of Big Toothbrush: how did our mouths become such a lucrative market?</div>

<div class="article-cover"><img src="https://i.guim.co.uk/img/media/bcedb0675401e252dffdc2ca65a69f0fef036205/0_0_2501_2000/master/2501.png?width=140&amp;quality=85&amp;auto=format&amp;fit=max&amp;s=abcf03e0b29d9e0d3049ca089a0d105e" alt="“大牙刷”崛起：我们的口腔是如何变成一个利润丰厚的市场的？" loading="lazy" /></div>

<div class="article-body" data-article-body="true"><p>英国人对口腔健康的关注前所未有——如今，你可以买到益生元牙膏和价格高达600英镑的牙刷。然而，我们仍处于一场严重的牙科危机之中。</p>
<p>1969年12月，消费者杂志《Which?》刊登了一篇报道，介绍一种相对较新的小设备。该杂志预测，许多人会把它作为圣诞礼物赠送出去：电动牙刷。对于那些还没见过电动牙刷的人，杂志这样描述道：“它的原理其实与普通牙刷没有太大不同——你有一根末端带着刷头的杆子。不同之处在于，电动牙刷会替你移动刷头。”进步确实不小。</p>
<p>近六十年过去，电动牙刷已经远不只是简单地来回抖动刷头：它们提供多种速度，还配备运动传感器，可以实时追踪你刷过哪些部位——有些甚至承诺提供牙龈按摩或清洁舌头的模式。价格从一款基础款欧乐B牙刷的大约25英镑，到一款飞利浦Sonicare牙刷的599.99英镑不等，后者可以提供“智能覆盖反馈”。最新的超级牙刷售价仅为419.99英镑，配备摄像头和内置水射流装置，能够清洁牙缝，并利用人工智能识别缝隙。这款产品由戴森研发，本质上仍然是一根末端带着刷头的杆子（尽管市场上还有另一款形似护齿套、配有独立刷毛的牙刷，宣称能在20秒内清洁牙齿）。</p></div>

### [macOS 的平铺式窗口管理器 rift](https://github.com/acsandmann/rift/)
<div class="original-title-sub"><span class="orig-tag">原文</span> rift - a tiling window manager for macos</div>

<div class="article-body" data-article-body="true"><p>加载时出错。请重新加载此页面。</p>
<p>Rift 是一款适用于 macOS 的平铺式窗口管理器，专注于性能和易用性。</p>
<p>请通过文档开始使用：</p>
<p>加入 #rift:matrix.org，参与讨论、获取支持并参与开发。</p>
<p>如果 rift 已成为你日常工作流程的一部分，可以考虑赞助其开发。</p>
<p>Aerospace 对我来说运行良好，但我想念动画效果，以及在一台显示器上使用全屏、同时在另一台显示器上工作的能力。我还更倾向于利用私有 API／未公开 API，因为它们往往更可靠（毕竟操作系统本身以及所有公开 API 都建立在这些 API 之上），性能也更好。关于 rift 存在的原因以及 rift 力求实现的目标，详见宣言。</p>
<p>Rift 最初是 glide-wm 的一个分支（并以分支项目的方式获许可），但此后已发生了很大分化。它使用了由 yabai 和其他项目逆向工程得出的私有 API。它与 glide-wm 或 yabai 没有隶属关系。</p>
